# GA4 導入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GA4 のページビュー計測と 6 種のカスタムイベント送信を、測定 ID が未設定なら完全に無効になる形で組み込む。

**Architecture:** `@next/third-parties` の `GoogleAnalytics` を `RootLayout` に置いてページビューを取る。イベントは `src/shared/lib/analytics/events.ts` の `trackEvent` 1 本に集約し、測定 ID が無いときは no-op にする。作成系ハンドラーは `redirect()` で成功をクライアントに返せないため、リダイレクト先 URL に `?created=…` を載せ、遷移先ページの `TrackCreated` が発火してクエリを消す。

**Tech Stack:** Next.js 16.3.3 (App Router) / React 19 / TypeScript / vitest + @testing-library/react / Biome / pnpm

## Global Constraints

- パッケージ管理は **pnpm** を使う（`pnpm add`、`pnpm test` など）。`npm` / `yarn` は使わない。
- 測定 ID の環境変数名は `NEXT_PUBLIC_GA_ID`。値が未設定または空文字なら、スクリプトもイベントも一切出さない。
- `process.env.NEXT_PUBLIC_GA_ID` は必ずこのリテラルで直書きする。`process.env[key]` のような動的アクセスは Next のビルド時置換が効かず、本番で `undefined` になる。
- イベント名は `sign_up` / `login` / `organization_create` / `tournament_create` / `division_create` / `record_result` の 6 種のみ。`AnalyticsEvent` 型に無い名前は追加しない。
- `src/shared/**` は `@/features/**` と `@/components/**` を import できない（Biome の `noRestrictedImports` で error）。`src/shared/lib/analytics/` 配下は `@next/third-parties/google` と同ディレクトリ内のみに依存すること。
- `sendGAEvent` はクライアント専用。`src/shared/lib/analytics/events.ts` を import してよいのは `"use client"` を宣言したファイルだけ。
- 各タスクの最後に `pnpm lint` と `pnpm typecheck` が通ること。コミットは各タスクの末尾で 1 回。
- コミットメッセージの末尾に必ず以下を入れる。

  ```
  Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>
  ```

- 作業ツリーには本計画と無関係な未コミット変更（`src/components/auth/LoginForm.tsx`、`LoginForm.test.tsx`、`src/shared/lib/mail/console-mailer.*`、`docs/superpowers/specs/2026-09-07-user-profile-design.md`）がある。worktree で作業する場合、Task 3 の `LoginForm` 変更は主ツリーの変更と衝突しうる。Task 3 の変更は import 1 行と呼び出し 1 行に留めてあるので、衝突時は手で再適用する。

```ts
/**

 * NEXT_PUBLIC_* はビルド時に文字列リテラルへ静的置換される。
```

```ts
"use client";

import { sendGAEvent } from "@next/third-parties/google";
import { gaMeasurementId } from "./ga-id";

/**
 * 送信してよいイベント名。GA4 は未知の名前も黙って受け付けてしまい、
 * タイポに送信後は気づけないため、ここで型として閉じている。
 */
export type AnalyticsEvent =
  | "sign_up"
  | "login"
  | "organization_create"
  | "tournament_create"
  | "division_create"
  | "record_result";

/**
 * GA4 へカスタムイベントを送る。
 * 測定 ID が無い環境では window.dataLayer に一切触らない。
 */
export const trackEvent = (
  name: AnalyticsEvent,
  params?: Record<string, string>,
): void => {
  if (gaMeasurementId() === null) return;
  sendGAEvent("event", name, params ?? {});
};
```

```tsx
"use client";

import { usePathname, useRouter } from "next/navigation";
import { useEffect } from "react";
import type { AnalyticsEvent } from "@/shared/lib/analytics/events";
import { trackEvent } from "@/shared/lib/analytics/events";

/**
 * 作成系の Server Action は成功時に redirect するため、useActionState の
 * state は更新されず、クライアントは成功を観測できない。そこで
 * リダイレクト先の ?created= を受け取り、遷移後に 1 回だけ発火する。
 */
const CREATED_EVENTS: Record<string, AnalyticsEvent> = {
  organization: "organization_create",
  tournament: "tournament_create",
  division: "division_create",
};

export function TrackCreated({ created }: { created: string | undefined }) {
  const router = useRouter();
  const pathname = usePathname();

  useEffect(() => {
    if (created === undefined) return;
    // URL は誰でも手で打てる。既知の値だけを通し、イベント名が
    // 外部入力で汚れないようにする。
    const event = CREATED_EVENTS[created];
    if (event === undefined) return;

    trackEvent(event);
    // クエリを消す。リロードや URL の共有で二重に計上されるのを防ぐ。
    // replace なので戻るボタンの履歴を汚さない。
    router.replace(pathname);
  }, [created, pathname, router]);

  return null;
}
```
